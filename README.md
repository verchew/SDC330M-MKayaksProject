# Lowcountry Kayak Booking System

A Java Object-Oriented Programming (OOP) terminal application designed to manage kayak rentals and coastal tour bookings.

### Features
* Terminal-based interactive menu with input validation for dates, emails, and phone numbers.
* Implements core OOP principles: interfaces, abstract classes, inheritance, polymorphism, and composition.
* Manages customer profiles, equipment rentals (single and tandem kayaks), guided tour reservations, and gear packages.
